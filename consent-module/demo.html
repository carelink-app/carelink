2️⃣ 관리자 — 응시자 동의서 목록

기본 비밀번호: admin1234 (consent.js의 ADMIN_PW_HASH에서 변경 가능)

3️⃣ 저장된 동의 정보 확인

버튼을 눌러보세요.

📌 통합 가이드 (CBT 웹에 붙이기)

  1. consent.js 파일을 웹 폴더에 복사
  2. HTML <head>에 추가: 
    <script src="consent.js"></script>
  3. 로그인 처리 직후 호출: 
    ConsentModule.start({
  onComplete: function(record) {
    // 시험 화면으로 이동
    window.location.href = '/exam';
  },
  onCancel: function() {
    alert('동의가 필요합니다');
  }
});
  4. (선택) Firebase 클라우드 저장 — Firebase 초기화 후: 
    window.CONSENT_FB = firebase.database();
  5. 관리자 페이지에서: 
    ConsentModule.openAdmin('비밀번호')
